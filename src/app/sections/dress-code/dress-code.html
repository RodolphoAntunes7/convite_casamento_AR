Dress Code

Sua presença é o nosso maior presente, e queremos que você se sinta incrível para celebrar conosco.

Para elas

Vestidos longos ou midi elegantes. Cores vibrantes ou tons pastéis são bem-vindos. Pedimos a gentileza de evitar o branco, off-white e o azul serenity (reservado para as madrinhas).

Para eles

Traje social completo. Como o evento será em julho, tecidos um pouco mais estruturados são uma ótima pedida para o conforto térmico durante a noite.
